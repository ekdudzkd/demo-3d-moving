# 모델 선택

> 초안. 수치는 공개 문서 기준 추정치이며 3단계(3-3, 3-6)에서 실측값으로 교체한다.

## 3D 생성

| 항목 | TripoSR (기본) | Stable Fast 3D (비교) |
|---|---|---|
| 라이선스 | MIT | Stability AI Community License (조건부) |
| 입력 | 512×512 RGB, 회색 배경 합성, 전경 비율 0.85 | 실측 시 기록 |
| 출력 | 정점색 OBJ (텍스처 베이크 옵션) | UV 텍스처 GLB |
| VRAM (추정) | 약 6GB (공식 README) | 실측 시 기록 |
| 시간 | 실측 예정 | 실측 예정 |
| 배포 | 기본 ON | 플래그, 기본 OFF |

선택 이유: 라이선스 제약이 가장 적고 입력·출력 구조가 단순해 adapter·전처리 실험의 기준선으로 적합.
